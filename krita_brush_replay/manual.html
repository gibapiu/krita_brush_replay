Brush Replay

Record freehand strokes on one paint layer.

Supports two replay modes:

  • Replay original settings to apply the preset, colours, size, opacity, flow, rotation, pattern, and blending mode captured at the start of each stroke.
  • Compare with current settings paints every recorded stroke with the settings currently selected in Krita. Your pre-replay settings are restored when either replay mode completes or fails.

This first version keeps recordings in memory and only replay to the same Krita document and layer. On current stable Krita releases, replay can create several undo steps, reset brush dynamics between short sections, and round positions to whole pixels.

⚠️ Replay promises identical settings, not identical pixels. Random brush engines and the legacy fallback can still vary.
