Brush Replay

Record freehand strokes on one paint layer.

Supports two replay modes:

  • Replay original settings to apply the saved preset selection, colours, size, opacity, flow, rotation, pattern, and blending mode captured at the start of each stroke.
  • Compare with current settings paints every recorded stroke with the settings currently selected in Krita and does not change them.

This first version keeps recordings in memory and only replay to the same Krita document and layer. On current stable Krita releases, replay can create several undo steps, reset brush dynamics between short sections, and round positions to whole pixels.

Only settings exposed reliably by Krita's scripting API are captured. Unsaved preset-engine tweaks, such as spacing and dynamics curves, and eraser mode are not recorded. Original-settings replay restores the captured pre-replay settings, but unsaved preset tweaks may not survive the preset being re-selected.

⚠️ Replay promises identical settings, not identical pixels. Random brush engines and the legacy fallback can still vary.
