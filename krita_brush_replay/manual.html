Brush Replay

Record freehand strokes on one paint layer and replay them on the active paint layer.

Use Record for new recordings and the active document's list. In Replay, choose any saved recording, including one from a closed document. Search by document or date; select a row and press Delete to remove it.

Replay modes:

  • Recorded settings paints with each stroke's saved settings and your edits.
  • Current settings paints with the settings currently selected in Krita.

Both replay modes use Krita's current global tablet pressure curve and Use Pen Pressure setting. Recordings store raw pressure; input calibration is not saved with strokes.

Open Edit strokes, then select strokes or press Select all strokes to change their settings. Settings that differ between selected strokes show `—`. Press ↺ next to a setting to return the selected strokes to the recorded value. Changed strokes are marked with ✎. Changing a preset keeps the stroke's own size, opacity, flow, rotation, and blending mode unless you change those too. Changes preserve the original settings, are saved with the chosen recording, and are ignored by Current settings.

⚠️ Limitations ⚠️

  • Record only one layer. Switching layers or documents will stop current recording and requre a new one
  • Each document keeps its 10 latest saved recordings. Recordings from documents that were never saved stay in memory and are lost on a document switch.
  • Only settings exposed reliably by Krita's scripting API are captured. Unsaved preset-engine tweaks, such as spacing and dynamics curves, and eraser mode are not recorded.
  • Replay restores the captured pre-replay settings and the settings of every preset it used, but unsaved preset tweaks may not survive the preset being re-selected.
  • Replay promises identical settings, not identical pixels. Random brush engines and event timing can still vary.
  • The blending-mode editor offers common modes only. Colours picked in the editor are stored as 8-bit sRGB.
  • Some brush engines round, clamp, or ignore size and rotation; replay paints with the values the engine accepts.
