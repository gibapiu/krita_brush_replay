Brush Replay

Record freehand strokes on one paint layer and replay them on the active paint layer.

Replay modes:

  • Replay paints on the active layer with the saved preset selection, colours, size, opacity, flow, rotation, pattern, gradient, and blending mode captured at the start of each stroke, including any changes you made to them.
  • Compare with current settings paints on the active layer with the settings currently selected in Krita and does not change them.

Select one or more strokes in the list or press Select all strokes to change their settings. Settings that differ between selected strokes show `—`. Press ↺ next to a setting to return the selected strokes to the recorded value. Changed strokes are marked with ✎. Changing a preset keeps the stroke's own size, opacity, flow, rotation, and blending mode unless you change those too. Changes never alter the recording, are discarded when a new recording starts, and are ignored by Compare with current settings.

For pressure bug reports, see Diagnostics.

⚠️ Limitations

  • Record only one layer. Switching layers or documents will stop current recording and requre a new one
  • Keep recording in memory. A new recording replaces the current one. No history support atm
  • Only settings exposed reliably by Krita's scripting API are captured. Unsaved preset-engine tweaks, such as spacing and dynamics curves, and eraser mode are not recorded.
  • Replay restores the captured pre-replay settings and the settings of every preset it used, but unsaved preset tweaks may not survive the preset being re-selected.
  • Replay promises identical settings, not identical pixels. Random brush engines and event timing can still vary.
  • The blending-mode editor offers common modes only. Colours picked in the editor are stored as 8-bit sRGB.
  • Some brush engines round, clamp, or ignore size and rotation; replay paints with the values the engine accepts.
